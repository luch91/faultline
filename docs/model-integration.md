# Model integration

The API uses `muse-spark-1.3` through Meta Responses at `https://api.meta.ai/v1/responses`. Extraction always uses Spark with JSON schema and Zod validation. Evidence excerpts must be exact source substrings. Investigation uses validated function tools and the independent simulator. The server model registry also defines `muse-wonder-1.0` for complex investigations. Clients cannot supply a model identifier.

The deterministic router uses Spark for routine validated workflows. It selects Wonder only when `WONDER_ENABLED=true` and the workflow has at least three steps, five conditions, three policy rules, two unknown observations, or two missing execution gates. Otherwise a complex workflow remains on Spark and the route records that Wonder is disabled. A Wonder transport failure permits one Spark fallback. The route is returned with the investigation response. Wonder has not yet been tested against live Meta responses in this branch, so this routing rule is provisional.

Live requests require `MODEL_CALLS_ENABLED=true`, `META_CREDITS_CONFIRMED=true`, `META_BILLING_MODE=Standard`, a nonempty `MODEL_API_KEY`, and a successful Durable Object budget reservation. A request reserves a conservative maximum token estimate. Actual token usage replaces the reservation only when the provider returns usage. Failed or usage-free calls are marked as unknown usage and retain conservative accounting. The ledger reports these states separately.

Pricing estimates use Standard rates of $1.25 input and $4.25 output per million Spark tokens, and $4 input and $20 output per million Wonder tokens. Each model call reserves against its own rate and output limit. These rates must be reviewed against [Meta pricing](https://dev.meta.ai/docs/pricing-rate-limits) before a live Wonder call and reconciled with Meta Billing. The ledger is not a provider billing guarantee.

Completed investigations keep server-side call attestations containing model IDs, response IDs, tool IDs, validated tool arguments, simulator results, token usage, accounting status, and route reason. Certificate export recomputes results and includes the attested calls in its integrity hash. Deterministic-only certificates have null model metadata. The public visual-preview Worker sets both `MODEL_CALLS_ENABLED` and `WONDER_ENABLED` to false.
